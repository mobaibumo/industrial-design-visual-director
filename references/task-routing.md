# Task Routing
|模式|允许范围|默认保持|
|---|---|---|
|cmf_transfer|指定颜色、材料、表面工艺|目标几何、组件、比例|
|local_edit|明确区域与指定组件变化|区域外全部设计，未授权属性|
|scene_transfer|背景、明确授权的摆放/光照|产品几何、CMF、组件|
|render_refinement|降噪、抗锯齿、清晰度与授权照明|全部产品设计；补全细节仍未验证|
|view_consistency_review|比较视角、分析未知、生成参考提示词|有证据的结构事实|
|visual_qa|分析既有结果，输出违规与修正|不自动编辑|

基于用户意图分流而非仅按关键词；混合请求分别列范围并按属性授权。脚本 route 不适合独立处理否定句、混合意图或指代关系。
单张 3/4 图请求准确后视图：索取 CAD/后视参考；概念推测必须标为“非精确设计参考”，不可承诺准确正投影。
缺少目标时提供 assets/task-brief.json 填写指南，请补目标产品图或可访问设计资料及参考角色；此时不输出虚构产品 DNA。
