# 三视图与跨视角一致性

## 根据输入选择执行路径

|输入与用途|执行方式|结论边界|
|---|---|---|
|仅一张产品图，希望展示三视图|记录可见结构与背面/顶部等未知；可生成概念性正、侧、俯视参考|concept_reference；标明“概念三视图，非精确设计参考”；推测不作为硬锁事实|
|仅一张图，要求准确工程三视图|请求可访问的 CAD/模型或可靠工程投影资料，暂停依赖未知几何的精确生成|不得静默降级成概念图；用户接受概念方案后才切换路径|
|同一模型导出的三个正交白模图|逐图绑定目标，统一 CMF、照明和中性背景，保持每张投影轮廓、开口与细节|provided_views；AI 上材质仍可能漂移，几何一致性需与各自白模比较|
|可访问 CAD/三维模型且有可用工具|从同一模型、同一姿态和同一尺度导出正交视图，再按需上材质|cad_projection；只有真实执行并验证过的投影可以记录为模型导出，AI 结果仍不能自动继承工程精度|
|已有多视图结果|比较每个视图与对应依据，再做跨视图审查|未提供或无法判定的视图为 NOT_TESTED/REVIEW；不声称全部通过|

模型路径存在不代表模型已检查。工具不支持该格式时请用户导出正交图；不得假装调用 Rhino/Blender。可靠工程图可辅助核对几何，但没有模型不能记录为 cad_projection。

## 视角与尺度

普通方案展示默认 front、right、top，说明采用“正视、右视、俯视”；用户指定左视、后视、底视时按其要求替换。先根据产品使用方向确定正面，不能可靠判断时提出一个关键问题。三个产品角度不等于三视图；透视的 3/4 图不可标注为准确正投影。

展示排版可独立标注三视角，不默认声称符合某工程投影标准。用户需要工程图时确认第一角/第三角投影和视图布局；禁止把左右视图镜像替代。记录相机朝向、正交状态、模型姿态、尺度依据、输出规格。已知尺寸才能标实际尺寸，不把图片像素当毫米。

正视与侧视核对高度、正视与俯视核对宽度、侧视与俯视核对深度。只有相同投影与尺度依据时才作直接尺寸比较；独立自动裁切或透视图先标记不可直接比较。不擅自拉伸产品以凑齐边界。展示统一产品尺度、留白与标注位置；工程投影遵循用户要求。

## 结构与 CMF 约束

将共享的结构事实按同一个组件 ID 记录：体块、组件总数、开孔位置、接缝、连接关系。每张图分别注明可见、遮挡和未知；不同视图可见数量不相同不等于零件数量改变。各视图的投影轮廓分别锁定，不能要求不同视角保持同一个二维轮廓。

材质参考只提供 CMF，不提供几何。建立组件到材质的映射，例如 body=米白塑料、grip=棕色皮革、base=磨砂金属。三个视图使用同一映射，保留透明/半透明部件；同一材质的高光差异不直接认定为材质改变。白模零件边界不明时只澄清影响材质分配的区域。

三视图默认中性背景、受控一致照明和清楚可读的轮廓。用户同时要求生活场景时，优先把对齐三视图与场景展示分为两个输出；如用户只要场景中的三个角度，称“多角度展示”，不要冒称正交三视图。

## 数据与交付

在原任务单上增加 view_plan，结构见 assets/three-view-brief.json。mode 为 concept_reference、provided_views 或 cad_projection；accuracy 为 conceptual 或 source_constrained。工程精确性不能仅由枚举值授予；尚需真实模型/投影工具与人工核验记录。

views 各项记录 view、target_asset（对应白模或模型资产 ID）、projection（orthographic/perspective/unknown）、unverified。跨视角任务用 view_consistency_review；只为已有视图上材质可用 cmf_transfer，加上相同 view_plan。

提示词必须列出每个视图对应的目标依据、统一 CMF、投影与未知。没有结果时不创建 QA 报告。真实执行后在 manifest 中补充每个视图的结果路径、来源、实际工具和 QA 状态；合成示例和仅生成的提示词都不能写成已完成三视图。

有结果时逐视图检查七维，再汇总跨视角一致性，报告指出缺失视图。逐项记录：共享尺寸依据、视图方向/镜像、对应轮廓、组件关系、材质映射、视图标签、未知结构。明确硬锁漂移 FAIL；遮挡、资料不足或尺度不明 REVIEW；根本未检查 NOT_TESTED。视觉通过不等于工程几何验证通过。
